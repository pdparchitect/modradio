# Downloads and updates

The first public build is being prepared. Downloads will be available from [GitHub Releases](https://github.com/pdparchitect/modradio/releases).

## Install

Requires macOS 15 or later on Apple Silicon.

1. Download `ModRadio-arm64.zip` from Releases and unzip it.
2. Move **ModRadio** to **Applications** and open it.
3. Click the radio icon in your menu bar and choose **Play Random MOD or XM**.

ModRadio runs without a Dock icon. An internet connection is required to discover and download tracks. See [Using ModRadio](usage.md) for playback and media controls.

## Updates

Release builds provide **Check for Updates…** in the radio menu. The **Updates** submenu lets you control **Automatically Check for Updates** and **Automatically Download and Install** separately. Daily checks are enabled by default; automatic installation is opt-in.

Installing an update restarts ModRadio and stops the current track. Choose **Play Random MOD or XM** after relaunching to start listening again. Development builds have updates disabled.

See the [changelog](../CHANGELOG.md) for what changed and [security and privacy](security.md) for how downloads and updates are verified.
